# Circuitos

Editor visual de circuitos que genera código CircuiTikZ, con vista previa compilada con LaTeX y exportación a `.tex` y `.pdf`.

Este repositorio solo contiene las versiones publicadas. Descarga la última desde [Releases](https://github.com/jpacheco501/circuitos-releases/releases/latest):

- **Circuitos-Setup-x.y.z.exe**: instalador para Windows (sin permisos de administrador). La aplicación avisa cuando hay una versión nueva y se actualiza sola.
- **Circuitos-x.y.z-windows-x64.zip**: versión portátil.
- **circuitos.mcpb**: extensión para conectar Circuitos con Claude Desktop.
